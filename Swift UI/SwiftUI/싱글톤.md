# 싱글톤이란?
* 싱글톤은 앱 전체에서 객체를 딱 1개만 생성해서 공유하는 디자인 패턴

*싱글톤 예시*
```swift
class UserManager { // 유저 매니저라는 클래스 선언

    static let shared = UserManager() // 클래스 자체가 가지고있는 변수

    private init() { } // 외부에서의 생성을 막아 싱글톤을 유지
}
```

싱글톤 사용할때
```swift
UserManager.shared
```
이걸 쓴다

**한 인스턴스에 어느 클래스에서도 접근 가능하게 한 것 이다**

# 싱글톤을 사용 하는 이유
1. 메모리를 절약한다

2. 데이터를 일관성있게 유지를 할수있다

3. 어디서든 접근이 쉽다

# 싱글톤을 사용하는 상황
1. 사용자의 정보를 작성할때

2. 앱 설정을 관리할때

3. 서버 통신을 관리할때
