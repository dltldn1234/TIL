# 싱글톤이란?
* 싱글톤은 앱 전체에서 객체를 딱 1개만 생성해서 공유하는 디자인 패턴

*싱글톤 예시*
```swift
class UserManager { // 유저 매니저라는 클래스 선언

    static let shared = UserManager() // 클래스 자체가 가지고있는 변수

    private init() { } // 외부에서의 생성을 막아 싱글톤을 유지
}
```

싱글톤 사용할때
```swift
UserManager.shared
```
이걸 쓴다

**한 인스턴스에 어느 클래스에서도 접근 가능하게 한 것 이다**

# 싱글톤을 사용 하는 이유
1. 메모리를 절약한다
* 서버 통신을 할때 객체들을 많이 만들지 않는다 한개로 공유가 되기 때문에
```swift
URLSession.shared
```

2. 데이터를 일관성있게 유지를 할수있다
* 어디서 접근하던지 같은 사용자 정보를 사용하기 때문이다
```swift
UserManager.shared.username
```

3. 어디서든 접근이 쉽다
* 앱의 어느곳에서든 접근을 할 수가 있음
```swift
UserManager.shared
```
### 단 직접 static 변수로 만들어 줘야한다
* shared는 예약어가 아니라 개발자들이 만든 것 이기 때문이다

# 싱글톤을 사용하는 상황
1. 사용자의 정보를 작성할때
* 로그인한 사용자 정보를 앱 전체에서 공유할 때 편함
```swift
UserManager.shared.userName = "시우"
```
을 통해서 공유 가능

2. 앱 설정을 관리할때
*  다크모드,자동 로그인 등의 설정을 저장하고 관리하기 편함

```swift
UserDefaults.standard.set(true, forKey: "isDarkMode") 
```


3. 서버 통신을 관리할때
* 앱 전체에서 같은 객체를 사용한다

```swift
URLSession.shared.data(from: url) // URLSession객체를 공용으로 사용
```
