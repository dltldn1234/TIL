# 핵심 구성 요소 및 네이티브 구성 요소
1. React Native란?
* React Native는 React 와 앱 플랫폼의 네이티브 기능을 활용하여 Android 및 iOS 애플리케이션을 구축하기 위한 오픈 소스 프레임워크이다

2. React Native를 쓰는법
* React Native에서는 JavaScript를 사용하여 플랫폼의 API에 접근하고, 재사용 가능하고 중첩 가능한 코드 묶음인 React 컴포넌트를 통해 UI의 모양과 동작을 정의할 수 있음

# 네이티브 컴포넌트
안드로이드 개발에서는 Kotlin이나 Java로 뷰를 작성하고, iOS 개발에서는 Swift나 Objective-C를 사용함
**React Native에서는 React 컴포넌트를 사용하여 JavaScript로 이러한 뷰를 호출할 수 있음!**

> React Native 컴포넌트는 안드로이드 및 iOS와 동일한 뷰를 기반으로 하기 때문에 React Native 앱은 다른 앱과 마찬가지로 모양, 느낌, 성능을 제공할수가 있다

### 이러한 플랫폼 기반 컴포넌트를 네이티브 컴포넌트라고 한다

>**React Native를 사용하면 앱의 고유한 요구 사항에 맞춰 Android 및 iOS 용 네이티브 컴포넌트를 직접 구축할 수도 있다** 
**또한 커뮤니티에서 제공하는 다양한 컴포넌트들이 활발하게 활용되고 있어서 활용 가능함**

# 핵심 구성 요소

React Native는 컨트롤부터 액티비티 표시기까지 모든 것을 위한 다양한 코어 컴포넌트를 제공을 한다 이러한 컴포넌트들은 모두 API 섹션에서 문서화되어 있음

### 주로 다음과 같은 코어 컴포넌트를 사용을 많이함 

![alt text](<스크린샷 2026-08-09 오전 3.32.07.png>)

```
import {View, Text, Image, ScrollView, TextInput} from 'react-native';

const App = () => {
  return (
    <ScrollView>
      <Text>Some text</Text>
      <View>
        <Text>Some more text</Text>
        <Image
          source={{
            uri: 'https://reactnative.dev/docs/assets/p_cat2.png',
          }}
          style={{width: 200, height: 200}}
        />
      </View>
      <TextInput
        style={{
          height: 40,
          borderColor: 'gray',
          borderWidth: 1,
        }}
        defaultValue="You can type in me"
      />
    </ScrollView>
  );
};

export default App;
```
