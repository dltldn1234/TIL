# Baseurl이란?

* 웹 애플리케이션에서 요청을 보낼 때 공통으로 사용하는 가장 기초적인 서버 주소

**BaseUrl 은 서버의 주소 임!**

baseurl을 바로 변수로 선언을 하면 터지지는 않는데 let으로 선언을 해야 바뀌지 않는다 (중요함!)

다른 파일에서 baseurl을 알면 안된다 (private으로 선언)
