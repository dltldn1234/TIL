# 타입 캐스팅
* 현재 객체의 타입을 다른 타입으로 확인하거나 변환하는 것
    * 주로 상속 관계에서 사용

*예시*
```swift
class Animal {
    func sound() {
        print("동물")
    }
}

class Dog: Animal {
    func bark() {
        print("멍멍")
    }
}
```



# 1. Up Casting
    자식 -> 부모
전달 방식 

```swift
let dog = Dog()
let animal = dog as Animal
```
Dog 는 Animal이기 때문에 항상 가능하다

# 2. Down Casting
    부모 -> 자식
전달 방식

```swift
let animal: Animal = Dog()
```

# 3. as?
* 안전한 다운 캐스팅

    만약 dog 면 dog 변환해줘 아니면 nil(옵셔널)로 반환


# 4. as!
* 강제 다운 캐스팅

    무조건 dog니까 그냥 변환해 라는 뜻 만약 객체가 안맞으면 crash가 남
