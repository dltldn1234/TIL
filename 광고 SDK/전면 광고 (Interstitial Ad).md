# 전면 광고 (Interstitial Ad)

전면 광고는 화면 전체를 덮어서 표시되는 광고이다

사용자가 화면을 이동하거나 특정 작업이 끝났을 때 표시하는 광고이며 배너 광고보다 수익이 높은 편이다

다만 너무 자주 띄우면 사용자가 불편함을 느낄 수 있기 때문에 적절한 타이밍에 사용하는 것이 중요하다

## 특징

### 장점

- 광고 수익이 높은 편이다
- 사용자의 시선이 집중되어 광고 효과가 좋다
- 구현이 어렵지 않다
- AdMob에서 가장 많이 사용하는 광고 중 하나이다

### 단점

- 너무 자주 나오면 앱을 삭제할 가능성이 높아진다
- 사용자 경험(UX)에 영향을 줄 수 있다
- 잘못된 타이밍에 표시하면 심사에서 문제가 될 수도 있다

## 주로 사용하는 위치

전면 광고는 다음과 같은 상황에서 많이 사용된다

- 화면 이동 직전
- 게임 스테이지 종료 후
- 게시글 작성 완료 후
- 계산 완료 후
- 검색 결과 확인 후
- 페이지를 닫을 때

반대로

- 로그인 직후
- 앱을 실행하자마자
- 결제 중
- 중요한 입력 중

이런 상황에서는 사용하지 않는 것이 좋다

## 동작 방식

사용자가 특정 행동을 하면 미리 로드되어 있던 광고를 표시한다

```text
광고 미리 로드
      ↓
사용자 화면 이동
      ↓
전면 광고 표시
      ↓
광고 종료
      ↓
다음 화면 이동
```

## SwiftUI 사용 예시

```swift
interstitialAd.show(from: rootViewController)
```

광고는 미리 로드해두었다가 필요할 때 보여주는 방식으로 사용한다

## 수익 방식

전면 광고는 광고가 노출될 때마다 수익이 발생한다

배너 광고보다 단가가 높은 편이라 같은 사용자 수라도 더 높은 수익을 기대할 수 있다

예를 들어

- 하루 사용자 1,000명
- 전면 광고 2회 노출

↓

하루 약 2,000회의 광고 노출이 발생한다

## 사용할 때 주의할 점

- 앱 실행 직후 바로 띄우지 않는다
- 연속으로 여러 번 띄우지 않는다
- 사용자의 작업을 방해하지 않는 타이밍에 표시한다
- 광고가 끝난 후 자연스럽게 다음 화면으로 이동한다

## 정리

전면 광고는 화면 전체를 사용하는 광고이다

배너 광고보다 수익이 높지만 사용자가 불편함을 느끼기 쉬워서 적절한 타이밍에 사용하는 것이 중요하다

보통 배너 광고와 함께 가장 많이 사용하는 광고 방식이다
