# 네이티브 광고 (Native Ad)

네이티브 광고는 앱의 디자인에 맞게 자연스럽게 녹아드는 광고이다

일반 광고처럼 튀지 않고 게시글이나 카드 형태로 보여주기 때문에 사용자가 거부감을 덜 느끼는 편이다

뉴스 앱이나 커뮤니티 앱에서 가장 많이 볼 수 있는 광고 방식이다

## 특징

### 장점

- 앱 디자인과 자연스럽게 어울린다
- 사용자 거부감이 적다
- 클릭률이 높은 편이다
- 화면을 가리지 않는다

### 단점

- 구현이 다른 광고보다 어렵다
- 광고 디자인을 직접 구성해야 한다
- 배너 광고보다 작업량이 많다

## 주로 사용하는 위치

네이티브 광고는 다음과 같은 화면에서 많이 사용된다

- 게시글 목록
- 뉴스 목록
- 쇼핑 상품 목록
- 커뮤니티 피드
- SNS 피드

예를 들어

```text
게시글
게시글
게시글

──────────────
📢 광고
이 제품을 추천합니다
──────────────

게시글
게시글
게시글
```

사용자는 일반 게시글처럼 보지만 "광고"라는 표시가 함께 들어간다

## 동작 방식

광고를 받아와 앱에서 원하는 디자인으로 표시한다

```text
광고 요청
      ↓
광고 데이터 수신
      ↓
앱 디자인에 맞게 표시
```

## SwiftUI 사용 예시

```swift
NativeAdView()
```

배너 광고처럼 정해진 모양이 아니라 직접 UI를 만들어 사용한다

## 수익 방식

네이티브 광고는 광고가 노출되거나 클릭될 때 수익이 발생한다

사용자가 일반 콘텐츠처럼 자연스럽게 보게 되기 때문에 클릭률이 높은 편이다

## 사용할 때 주의할 점

- 반드시 광고라는 표시를 해야 한다
- 일반 게시글과 너무 똑같이 만들면 안 된다
- 앱 디자인과 자연스럽게 어울리도록 구성한다
- 사용자를 속이는 형태로 만들면 안 된다

## 정리

네이티브 광고는 앱 디자인에 맞게 자연스럽게 표시되는 광고이다

사용자 경험을 크게 해치지 않으면서도 광고 효과가 좋은 편이라 뉴스 앱이나 커뮤니티 앱에서 많이 사용된다

구현 난이도는 가장 높지만 사용자 만족도도 높은 광고 방식 중 하나이다
