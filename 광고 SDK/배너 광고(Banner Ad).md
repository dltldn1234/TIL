# 배너 광고 (Banner Ad)

배너 광고는 앱 화면의 상단이나 하단에 고정되어 표시되는 광고이다

앱을 사용하는 동안 계속 노출되기 때문에 가장 기본적인 광고 형식으로 많이 사용된다  
사용자 경험을 크게 방해하지 않아 대부분의 앱에서 사용하며 구현도 비교적 간단한 편이다

## 특징

### 장점

- 구현이 쉽다
- 사용자 흐름을 크게 방해하지 않는다
- 화면에 계속 노출되어 광고 노출 수가 많다
- 대부분의 앱에서 자연스럽게 사용할 수 있다

### 단점

- 클릭률이 낮은 편이다
- 전면 광고보다 수익이 적다
- 사용자가 광고를 무시하는 경우가 많다

## 주로 사용하는 위치

배너 광고는 다음과 같은 화면에서 많이 사용된다

- 홈 화면
- 게시글 목록
- 설정 화면
- 뉴스 앱
- 커뮤니티
- 계산기
- 메모 앱

반대로 로그인, 회원가입, 결제 화면처럼 중요한 화면에서는 사용하지 않는 경우가 많다

## 동작 방식

앱이 실행되면 AdMob 서버에 광고를 요청하고 광고가 정상적으로 로드되면 화면에 표시된다

```text
앱 실행
   ↓
광고 요청
   ↓
광고 로드
   ↓
배너 광고 표시
```

## SwiftUI 사용 예시

```swift
BannerAdView()
    .frame(height: 50)
```

보통 화면의 가장 아래에 배치해서 사용한다

## 수익 방식

배너 광고는 주로 광고가 화면에 노출된 횟수(Impression)를 기준으로 수익이 발생한다

예를 들어 사용자가 하루에 앱을 10번 실행하고 배너 광고가 매번 표시된다면 광고 노출도 약 10회 발생하게 된다

광고를 클릭하면 추가 수익이 발생할 수도 있다

## 정리

배너 광고는 가장 많이 사용하는 광고 방식이다

구현이 쉽고 사용자에게 부담을 주지 않는다는 장점이 있지만 전면 광고나 리워드 광고보다 수익은 낮은 편이다

그래서 대부분의 앱에서는 배너 광고와 다른 광고 형식을 함께 사용하여 수익을 높인다
